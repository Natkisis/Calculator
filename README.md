# Calculator
Веб-калькулятор с красивым дизайном и клавиатурной поддержкой
Разработано с использованием чистого JavaScript

Управление
1. Мышь - Клик по кнопкам
2. Клавиатура - Полная поддержка:
- Цифры 0-9
- Операторы +, -, *, /
- Enter или =
- Очистка C или Escape
- Точка .
- Удаление Backspace

Технологии
- HTML5 - Семантическая разметка
- CSS3 - Modern стили с Flexbox
- JavaScript ES6+ - Использование классов
- Glassmorphism - Стеклянный эффект интерфейса

Будущие улучшения
- Добавление памяти (M+, M-, MR, MC)
- Поддержка дополнительных операций (%, √, x²)
- История вычислений
- Темная тема
- Научный режим
